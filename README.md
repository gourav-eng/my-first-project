# Nexus Workflow Workspace - Enterprise Edition

A premium infinite canvas workflow and project management tool with full mobile support.

## Features

- **Infinite Canvas**: Drag, zoom, and pan across an unlimited workspace
- **Mobile-Optimized**: Pinch-to-zoom gestures and touch-friendly controls
- **Dual View Mode**: 
  - Canvas View (spatial drag-and-drop)
  - Outline Board View (structured list for mobile)
- **Nested Groups**: Create hierarchical project phases with auto-layout
- **Task Management**: Priority levels, status tracking, and progress analytics
- **Touch Controls**: Bottom sheet action panels for mobile devices
- **Theme Customization**: Multiple color themes for visual organization
- **Image Attachments**: Drag-and-drop images with compression
- **Undo/Redo**: Full history tracking
- **Export/Import**: Save and load your workflows as JSON

## Installation

```bash
npm install
npm start
```

## Usage

- **Desktop**: Right-click for context menus, drag nodes and groups
- **Mobile**: Pinch to zoom, tap for bottom sheet controls, use Outline Board for precise edits
